# Brand assets

Regenerate with `node scripts/brand-assets.mjs` (needs the fonts in `/tmp/ncfonts`).
Text is converted to vector outlines, so these don't depend on a font being
installed anywhere.

| File | Size | Use |
|---|---|---|
| `profile-tiger-face.png` | 640×640 | **Profile picture.** Still readable at comment size. |
| `profile-monogram.png` | 1080×1080 | Alternative profile picture — elegant, but the thin script fades when small. |
| `profile-tiger.png` | 640×640 | Alternative — the whole motif; the roses are lost to the circular crop. |
| `post-wordmark.png` | 1080×1080 | Square post — wordmark and tagline. |
| `post-tiger.png` | 1080×1080 | Square post — motif over the wordmark. |
| `story.png` | 1080×1920 | Story, carries the web address. |

Colours are the brand's own: Black Coffee `#0e0b09`, Vermilion `#e8382f`,
Cigar `#8f5a4a`, Bone `#ece9df`. Type is Pinyon Script and Space Grotesk.
